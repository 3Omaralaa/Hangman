# 🎮 Hangman Game

A simple Hangman game built with Python.  
The player tries to guess the hidden word by entering letters. If too many wrong guesses are made, the game ends.

## ✨ Features
- Random word selection from a word list.
- Display of the word as underscores `_` for hidden letters.
- Updates the word with each correct guess.
- Game ends with either a win or a loss.
